# Network Security Lab — 5-Module Practical

A hands-on network security lab conducted over 10 weeks using an isolated 
Kali Linux / Ubuntu Server virtual environment.

## Tools & Technologies
- Kali Linux / Ubuntu Server 24.04
- Nmap
- Wireshark
- UFW / iptables
- VirtualBox

## Modules Covered
1. Virtual lab setup — isolated network environment
2. Host discovery and SYN port scanning with Nmap
3. OS fingerprinting and service enumeration
4. Traffic capture — plaintext HTTP vs encrypted TLS/SFTP comparison
5. Firewall configuration — UFW default-deny policy with verified rule enforcement

## Key Skills Demonstrated
- Network reconnaissance and host discovery
- Protocol analysis (FTP vs SFTP, HTTP vs HTTPS)
- Firewall rule design and verification
- Traffic capture and analysis in Wireshark
